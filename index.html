Customer Segmentation & Clustering Analysis

Applied unsupervised machine learning to segment customers into distinct groups for targeted marketing strategies.

Project Overview

This project uses unsupervised machine learning to identify natural customer groupings from behavioral and demographic features. K-Means clustering was the primary model, validated against hierarchical (agglomerative) clustering, with the optimal cluster count chosen via the elbow method and silhouette analysis.

Technologies Used

Python Scikit-learn Pandas Matplotlib Seaborn

Key Outcomes

  • ✅ Identified 5 distinct customer segments with clear characteristics
  • ✅ K-Means and hierarchical clustering agreed on structure (Adjusted Rand Index: 0.845)
  • ✅ Recovered underlying segment structure with 94.5% validation accuracy
  • ✅ Enabled personalized marketing & retention strategy per segment

Challenges Overcome

  • 🔷 Determining the optimal number of clusters
  • 🔷 Feature scaling and normalization across variables
  • 🔷 Validating cluster stability across two algorithms
  • 🔷 Translating statistical clusters into business-ready segments

Key Insights

High-Value segment (15.2%) generates the highest average CLV (~$5,307) — prioritize retention.
Growth Potential segment (26.4%) shows strong spend at moderate income — best upsell target.
Loyal segment (28.2%) is the largest group with long tenure — ideal for loyalty programs.
At-Risk segment (16.9%) shows low activity — needs immediate re-engagement.
